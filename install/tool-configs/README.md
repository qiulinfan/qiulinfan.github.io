# 工具配置与操作笔记

这里保存我为了在不同机器上复用工具配置而记录的操作流程，也可以视作带有详细说明的个人教程。

- [`Shells/`](Shells/)：bash、zsh、fish、PowerShell 与终端主题配置。
- [`Editors/`](Editors/)：VS Code、Cursor、vim、Neovim 的配置文件和使用方法。
- [`OSconfigs/`](OSconfigs/)：Linux、Windows/WSL、macOS 与 Python 环境的安装和配置笔记。
- [`decorations/`](decorations/)：光标等桌面装饰资源及其来源说明。
- [`wallpapers/`](wallpapers/)：配置引用的壁纸资源。
- [`git_notes.md`](git_notes.md) 与 [`python_notes.md`](python_notes.md)：独立工具笔记。

本目录从私有仓库
[`qiulinfan/MyToolConfigs`](https://github.com/qiulinfan/MyToolConfigs)
的当前快照迁入；旧仓库历史刻意不导入。迁移边界和变换记录见
[`MIGRATION.md`](MIGRATION.md)。

这是公开内容。个人路径和用户名按确认保留；原有 IP 已替换为 `.example` 主机名或显式占位符，
使用配置前需要按目标机器填写本地值。
