# Legacy template provenance

`qlmathnotes.sty.tmpl` replaces, but does not load or synchronize with, the
retired ElegantBook class formerly stored in
[`qiulinfan/localLatexenv`](https://github.com/qiulinfan/localLatexenv) and in
this Skill. The last synchronized local template was recorded at
`f62053086eec079f6c7db99eac23d9c66e28b63f`.

ElegantBook's upstream is
[`ElegantLaTeX/ElegantBook`](https://github.com/ElegantLaTeX/ElegantBook) and is
distributed under the LaTeX Project Public License, version 1.3c or later. The
replacement package retains that license and source acknowledgement because it
preserves a limited compatibility surface for existing authoring commands and
environment names.

This provenance is historical and legal metadata, not a runtime or refresh
dependency. Generated projects receive the package source and its LPPL header;
they never read qlblog, `localLatexenv`, an ElegantBook class, or an external
template repository. Do not refresh or overwrite `qlmathnotes.sty.tmpl` from
either legacy repository.
